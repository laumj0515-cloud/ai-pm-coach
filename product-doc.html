01 · 项目背景

为什么需要这个工具

刘美姣，2 年产品经验，正从家居行业转 AI 产品经理。一年 Gap 期独立开发了 Tempo（AI 执行力干预小程序）和 Mibo（AI 情感陪伴 Agent）。求职过程中发现几个核心痛点：

🎯

岗位名不副实

JD 写"应用层 AI PM"，面试问的全是模型层问题（DeepSeek 参数量、embedding 原理）。需要练的是如何识别并优雅地回应——"这不是我该答的方向"。

🔄

表达能力弱环

思维强但表达跳跃。面试时容易把内心逻辑密度变成信息过载，说很多但没说到点上。需要训练结构化输出。

📊

数据支撑不够

Tempo 和 Mibo 明明有真实数据和产品沉淀，但面试时无法快速调用。需要反复训练"用数据说话"的肌肉记忆。

📝

无法模拟真实追问

跟自己练习看不出问题。需要一个严格、会打断、会追问"不够具体"的真实面试官来对练。

02 · 解决方案

一个记住你全部底牌
的 AI 面试教练

Stitch 不是通用面试题库。它从一开始就知道刘美姣的背景、项目、薄弱点， 在每一轮对话中针对性地追问，并在每次回答后给出即时反馈。

核心设计原则

不是问题库，而是对话引擎。 它需要听懂你说了什么，判断你是否真的回答到了问题。

不是鼓励型，而是严苛型。 因为你对敷衍极敏感，假装满意的反馈对你没用。

不止练表达，还练边界感。 遇到模型训推、embedding 这类不属于应用层 PM 的问题，它会告诉你—— "这不是你该答的方向"，而不是让你硬撑。

01

四种面试模式 已上线

🚀 初创创始人 — 追问你能不能独立扛事 · 💼 HR 面试官 — 追问 gap 和薪资 · ⚙️ 技术 PM — 深挖产品架构逻辑 · 💰 薪资谈判 — AI 有隐藏预算，模拟真实谈薪

02

实时反馈系统 核心亮点

每答完一题立刻收到点评：✅ 哪里好 · ❌ 哪里需要改善（具体到用词） · 💡 更好的答法示范。不等最后一次性复盘，而是每题即时修正。

03

语音通话模式 像打电话

支持连续语音对话。3 秒思考停顿自动发送，AI 回复 TTS 朗读。可以做家务时练面试。支持 Chrome / Safari（需 HTTPS）。

04

个人档案记忆 持久化

你的背景信息（Tempo、Mibo、Gap 原因、转行逻辑、薪资底线）写入 AI 的 system prompt。每次练习不用重新交代背景，AI 全知道。

05

进度追踪 迭代中

练习次数、平均分、反复出现的薄弱点标签。追踪你在"表达简洁度""数据支撑""逻辑结构""亮点突出"四个维度的进步曲线。

04 · 为什么不用 ChatGPT 直接练

传统方式 vs Stitch

通用 AI 聊天 Stitch
记住你的项目 需要每次重新交代 ✅ 档案持久注入 system prompt
追问深度 泛泛，不针对个人弱点 ✅ 知道你的薄弱点，定向深挖
即时反馈 不会主动点评每道题 ✅ 每答即评 ✅❌💡三色标注
语音通话 不支持连续对话 ✅ 持续聆听 + TTS 朗读回复
进度追踪 无 ✅ 分数趋势 + 薄弱点标签
面试模式 需要手动构造 prompt ✅ 创始人/HR/技术PM 一键切换
数据隐私 上传云端 ✅ 全部存本地 localStorage
05 · 技术架构

轻量、离线友好、手机优先

React 18 Vite Tailwind CSS DeepSeek API Web Speech API localStorage Netlify HashRouter
🧠

AI 引擎

DeepSeek Chat API（OpenAI 兼容）。System prompt 注入个人档案 + 面试官人设，每轮对话带明确指令确保反馈格式稳定。支持自定义 JD 模式。

🎤

语音层

浏览器原生 Web Speech API（SpeechRecognition + SpeechSynthesis）。Chrome / Safari 均可使用。3 秒静默阈值自动发送，支持思考停顿。

💾

数据层

全量 localStorage 本地存储 —— 个人档案、API Key、面试记录、评分数据。不上传任何服务器。同一浏览器内持久化。

🚀

部署

Vite 构建为纯静态文件 → Netlify 自动部署。Git push 即上线。自带 HTTPS，Safari 语音功能可用。国内无需翻墙访问。
